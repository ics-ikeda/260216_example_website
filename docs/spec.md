# Spectrum Night 外部仕様

## 1. 本書の範囲

- 本書は、Figmaでは確定しない挙動仕様のみを定義する。
- 画面の見た目、文言、レイアウト、余白、色、タイポグラフィ、画像選定はFigmaを正とし、本書では重複記載しない。

## 2. ナビゲーション挙動

- ヘッダーメニューは開閉可能な全画面オーバーレイとして動作すること。
- メニュー内リンク選択時は、対象セクションへページ内遷移し、メニューを閉じること。
- ページ内遷移はスムーズスクロールで行うこと。
- メニュー表示中は背景スクロールを禁止すること。
- メニュー開閉時に、スクロール位置を補正するための独自ロジックは持たないこと。

## 3. 作品詳細（ライトボックス）挙動

- 作品サムネイルをクリックすると、全画面の詳細表示を開くこと。
- 詳細表示では次の操作で閉じられること。
  - 閉じるボタン
  - 背景クリック
  - `Esc` キー
- 詳細表示では前後の作品に移動できること。
- 前後移動はボタン操作とキーボード左右キーの両方に対応すること。
- 作品インデックスは循環すること。
- 詳細表示中は背景スクロールを禁止すること。

## 4. 演出要件

- メニュー開閉には短時間のトランジションを適用すること。
- メニュー項目は同時表示ではなく、順次表示で開くこと。
- サムネイルから詳細表示への遷移は、フェード遷移とすること。
- 詳細表示内の前後移動は、フェード遷移とすること。
- 詳細表示のクローズ時は、フェード遷移で閉じること。
- インタラクティブな要素にはホバー時の視覚フィードバックを設けること。
- オーバーレイの背景色は `dialog::backdrop` で表現し、`dialog` 本体の背景は透明とすること。

## 5. 未接続導線

- 「more works」は現時点で遷移先未設定とする。
- 「お問い合わせ」は現時点で送信先未設定とする。

## 6. 一覧画像レスポンシブ挙動（可変前提）

- 本節は、`Work` と `Team` の一覧画像について、固定値ではなく挙動ルールを定義する。
- ブレークポイント値そのものは実装側で可変とし、同一のモバイル境界で `Work` と `Team` を切り替えること。

### 6.1 Work 一覧

- モバイルより広い表示では複数列、モバイルでは単列に切り替えること。
- 各画像カードは利用可能幅に応じて伸縮し、一覧領域内で均等に並ぶこと。
- カードは横長の画角を維持し、画面幅が変わっても比率が破綻しないこと。
- 狭い画面ではカード幅の上限制約を緩め、横余白を優先して可読性を保つこと。

### 6.2 Team 一覧

- モバイルより広い表示では複数列、モバイルでは単列に切り替えること。
- カードは一覧領域内で均等配置し、狭い画面では1カードずつ縦に積むこと。
- 画像の画角は、デスクトップ表示とモバイル表示で切り替え、人物の見え方を優先できること。
- 狭い画面ではカード幅の上限制約を緩め、親幅に追従させること。

### 6.3 共通ルール

- 画像は常に表示枠を埋める方式とし、必要に応じてトリミングを許容すること。
- 画像表示サイズは固定ピクセル前提にせず、親コンテナに対する相対サイズで決定すること。
- 実装時に固定値が必要な場合でも、将来の調整を前提に置換しやすい構造で定義すること。
